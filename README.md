# SCIA Magna 200 - Process Viewer

## Quick Start (On Any Computer)

1. Install Python 3 from https://www.python.org/downloads/ 
2. Click 'Code -> Download ZIP' on GitHub and extract the folder.
3. On Windows: double-click 'start_windows.bat'. On macOS/Linux/WSL: run './start_mac_linux.sh'.
4. Place new run folders inside 'SCIA logs/' and click Refresh in the app.
